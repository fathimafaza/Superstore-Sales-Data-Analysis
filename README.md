# Superstore Sales Data Analysis

## Project Overview
This project analyzes the Superstore Sales dataset using Python and Jupyter Notebook.

## Objectives
- Analyze sales and profit
- Identify top-performing products and categories
- Understand customer and regional sales trends
- Generate useful business insights from the data

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `Superstore_Sales.csv` – Dataset
- `Superstore_Sales_Data_Analysis.ipynb` – Jupyter Notebook containing the analysis

## Key Analysis
The notebook includes data cleaning, exploratory data analysis, visualizations, and business insights based on the Superstore Sales dataset.

## Conclusion
This project demonstrates how Python-based data analysis can be used to understand sales performance and support business decision-making.
